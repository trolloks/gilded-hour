**The Gilded Hour** is a complete browser heist game set in Meridian House, 1936. Cross three art-deco floors, read the guards' sweeping vision cones, slip the cameras, cut the laser seams, take the stone, and reach the lift. It runs offline from static files: no network request, no build step.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Move with **WASD**, run with **Shift**, sneak with **Ctrl**, interact with **E**, throw smoke with **Q**, fire an EMP with **F**, toss a decoy with **R**. The alarm gauge is the health bar: stay out of the light.
